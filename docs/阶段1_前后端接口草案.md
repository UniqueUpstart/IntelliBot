# IntelliBot 前后端接口草案 v0.3

本文件描述当前仿真后端的 HTTP 协议。接口由本项目提供，不是任何设备厂商的接口。
同源部署、单浏览器会话，只影响 MuJoCo 仿真，不连接 ROS 2 或真机。

## 1. 通用返回结构

~~~json
{"request_id":"req-001","data":{},"error":null}
~~~

HTTP：400 参数错误，404 不存在，409 幂等键冲突，422 当前能力不支持，503 未连接或去重窗口已满，502 仿真桥不可用。
写操作必须带 `Idempotency-Key`；同键同内容返回原结果，同键不同内容返回 409。

## 2. 接口

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | /api/v1/health | 后端健康；`mode` 为 sim 或 mock |
| POST | /api/v1/connections | `{"mode":"sim"}` 连接仿真桥；`{"mode":"mock"}` 纯内存模拟 |
| GET | /api/v1/connection | 连接状态与当前模式 |
| DELETE | /api/v1/connection | 断开；仿真模式下同时向桥发 stop |
| GET | /api/v1/status | 连接状态、电量占位、可用能力 |
| GET | /api/v1/capabilities | 动作白名单与仿真能力开关 |
| POST | /api/v1/tts | `{ text, interrupt }`，模拟受理 |
| GET/PUT | /api/v1/audio | 读取或设置音量、静音 |
| POST | /api/v1/actions | `{ action_id }`，白名单 `q1.wave` / `q1.heart` / `q1.cheer` |
| GET | /api/v1/logs?after_id=&limit= | 增量读取本系统日志 |
| GET | /api/v1/operations/{id} | 查询单个操作结果 |
| GET | /api/v1/sim/joints | 关节表、限位与相机参数 |
| GET | /api/v1/sim/state | 关节、接触、足底、步数与相机状态 |
| GET | /api/v1/sim/frame | JPEG 单帧 |
| POST | /api/v1/motion/base | `{ vx, vy, wz }`，限幅后转发桥 |
| POST | /api/v1/motion/stop | 清除速度并停止 |
| POST | /api/v1/control/joints | `{ joints, duration_ms }` |
| POST | /api/v1/control/gesture | `{ name, speed }` |
| POST | /api/v1/sim/preset | `{ name }` 预设姿态 |
| POST | /api/v1/sim/gait | `{ name }` 步态，空名或 off 表示停止 |
| POST | /api/v1/sim/mode | `{ mode: kinematic \| dynamic }` |
| POST | /api/v1/sim/camera | `{ azimuth, elevation, distance, reset }` |
| POST | /api/v1/sim/speed | `{ speed }` |
| POST | /api/v1/sim/reset | 复位模型 |

未启动 `--sim-url` 时，所有 `/sim/*`、`/motion/*`、`/control/*` 统一返回 422，
不会伪装成可用。

## 3. 数据约定

- 已移除：`/api/v1/robots`、`robot_id` 参数、`ros2_implemented`、`verified_on_robot`。
- 操作结果中 `state` 为 `applied`（仿真桥真的执行）或 `simulated`（只记录），
  对应布尔字段 `sim_executed`。
- 电量是仿真占位值，`source` 为 `sim` 或 `mock`；信号强度返回 null。
- 前端只使用相对路径 `/api/v1`，不拼接仿真桥地址。

## 4. 前端接入规则

- Advance → 连接仿真：先 POST connections，再 GET sim/joints；失败时在面板显示原因。
- 断开、页面失焦、Esc 都要调用停止接口；软件停止不等于物理急停。
- 未连接时禁用关节、手势、步态与移动控件，不缓存旧画面。
- 日志面板只展示后端内存日志，不做持久化。

## 5. 联调顺序

1. mock：连接、状态、播报、动作、音量、日志、幂等。
2. 仿真：桥 /health → 连接 → 关节表 → 关节/预设/手势/步态 → 画面 → 断开。
3. 异常：桥未启动（502）、未连接（503）、非法参数（400/422）、重复键（409）。
